# Changelog

All notable changes to Super Study are documented here. The project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-07-20

### Added

- Adaptive mastery protocol with progressive questioning and evidence gates.
- Technical interview, resume/project deep-dive, and behavioral interview tracks.
- Job-description targeting and source-grounded learning workflows.
- Duplicate-resistant Concept identity and resolution rules.
- Optional Obsidian Vault templates, navigation, indexes, and checkpoints.
- Deterministic Python CLI for Vault initialization, validation, and learning state.
- Cybersecurity authorization and isolation safeguards.
