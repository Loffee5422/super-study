# Code of Conduct

Super Study is committed to a welcoming, constructive community for learners and contributors of every background and experience level.

## Expected behavior

- Be respectful, patient, and specific.
- Critique ideas and implementations, not people.
- Treat beginner questions as legitimate learning needs.
- Respect privacy, confidentiality, consent, and security boundaries.
- Give credit for ideas, research, code, and documentation.
- Accept correction and focus on improving the project.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, sexualized attention, deliberate humiliation, credential exposure, sharing private interview material, or encouraging unauthorized security testing is not acceptable.

## Enforcement

Project maintainers may edit or remove contributions and restrict participation when behavior violates these standards. Report conduct concerns privately through the maintainer's GitHub profile or a private security advisory when sensitive information is involved. Reports will be handled as confidentially as practical.
